# События, система очков и появление босса

## Введение
Цель этапа – внедрить игровые события, систему подсчёта очков и связанную с ними логику (появление босса, победная музыка) с использованием ScriptableObject-каналов событий и паттерна MVC. Вся новая функциональность основана на слабосвязанных каналах, а менеджеры вынесены в чистые классы, не наследующие MonoBehaviour.

## Основные изменения

### 1. ScriptableObject-каналы событий
В проект добавлены три канала, размещаемые как ассеты:
- `VoidEventChannelSO` – событие без параметров (для появления босса и музыки).
- `IntEventChannelSO` – событие с целочисленным значением (счёт очков).
- `EnemyKilledEventChannelSO` – событие, содержащее структуру `KillData` (флаг «босс» и ценность в очках).

Каналы позволяют развязать отправителей и получателей событий без прямых ссылок.

### 2. Менеджеры логики (чистые классы)
- **ScoreManager** – хранит текущий счёт. Подписывается на `EnemyKilledEventChannelSO` и при каждом убийстве добавляет очки, затем уведомляет подписчиков через `IntEventChannelSO`.
- **KillManager** – отслеживает количество убитых обычных врагов. При достижении 3 убийств пускает событие `VoidEventChannelSO` для активации босса, при 5 – для победной музыки. Босс не учитывается в счётчике.

Оба класса не зависят от Unity API, легко тестируются и не привязаны к конкретным сценам.

### 3. Интеграция в сцены
#### `GameplayEntrypoint` (сцена с игрой)
- В методе `Awake` создаются экземпляры `ScoreManager` и `KillManager`, им передаются соответствующие каналы (сериализованные поля в инспекторе).
- В `OnDestroy` вызывается `Dispose` для корректной отписки от событий.

#### `GameEntrypoint` (глобальный синглтон)
- Содержит ссылку на канал `victoryMusicEvent` и аудиоклип. При получении события проигрывает победную мелодию через свой аудиосервис.

#### `SpawnManager`
- Добавлена логика появления босса: объект босса (`bossObject`) изначально неактивен. При событии `bossSpawnEvent` он активируется. При очистке всех врагов (`ClearAllEnemies`) босс снова скрывается.

### 4. UI
- `GameplayView` (уже существующий) расширен: добавлен текстовый элемент `scoreText` и ссылка на канал `IntEventChannelSO`. При старте и при каждом изменении счёта обновляется текст.

### 5. Враги и босс
Каждый враг (`MeleeEnemy`, `EvilWatcher`) при смерти вызывает `enemyKilledEvent.RaiseEvent(...)` с параметрами `IsBoss = false` и значением очков. Босс делает то же самое, но с `IsBoss = true` и повышенной ценой.

## Структура изменённых/новых файлов

| Файл | Назначение |
|------|------------|
| `VoidEventChannelSO.cs` | Канал событий без аргументов |
| `IntEventChannelSO.cs` | Канал событий с `int` |
| `EnemyKilledEventChannelSO.cs` + `KillData` | Канал убийства врага с данными |
| `ScoreManager.cs` | Чистый класс подсчёта очков |
| `KillManager.cs` | Чистый класс отслеживания убийств |
| `SpawnManager.cs` | Добавлена активация босса, скрытие при очистке |
| `GameplayEntrypoint.cs` | Инициализация менеджеров, передача каналов |
| `GameEntrypoint.cs` | Подписка на музыку победы |
| `GameplayView.cs` | Отображение счета, подписка на канал |
| `MeleeEnemy.cs`, `EvilWatcher.cs`, `BossEnemy.cs` | Отправка событий при смерти |

## Заключение
В результате работы:
- Система очков работает через ScriptableObject-события, полностью отделена от UI.
- Босс появляется строго после трёх убитых обычных мобов.
- Победная мелодия звучит после пятого убийства.
- Логика вынесена в чистые классы, MonoBehaviour-компоненты используются только для связывания с Unity и отображения.
- Модульность позволяет легко расширять систему (добавлять новые награды, менять пороги, вводить другие события).
