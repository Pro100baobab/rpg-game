# Вариативность врагов, стихийный босс, фабрики

## Введение
На данном этапе в проект добавлена глубокая кастомизация врагов и босса, внедрены паттерны «Фабрика», «Абстрактная фабрика», «Фабричный метод». Реализована расширенная система спавна врагов с возможностью динамического добавления точек через UI.

## Основные изменения

### 1. Вариативность обычных врагов
- **MeleeEnemy (милишник)** теперь может использовать **два вида оружия**: в правой или левой руке (только одна рука вооружена). Выбор оружия происходит случайным образом из заданных префабов.  
  Класс `MeleeEnemy` получил:
  - `SetRandomWeapon()` – случайно выбирает руку и оружие.
  - `SetWeaponsByIndex(int, int)` – для восстановления конкретных индексов из сохранения.
  - Сохранение индексов оружия в полях `RightWeaponIndex`, `LeftWeaponIndex`.
- **EvilWatcher (дальник)** получил **два типа атаки**:
  - `Fireball` – классический фаербол.
  - `Needle` – игольная атака: последовательный выстрел иглами по кругу (шаг 45°) с вращением персонажа.
  - Свойство `CurrentAttackType` и публичный сеттер для установки.
  - Сохранение типа атаки в `GameData`.

### 2. Спавнеры и точки спавна
- Класс **`SpawnManager`** полностью заменил старый `SpawnController`.
  - Поддерживает динамическое добавление точек спавна через UI (кнопка «Add Spawn Point» создаёт визуальный маркер перед камерой).
  - При спавне (`SpawnEnemies`) случайным образом выбираются точки, без повторений в рамках одного вызова. Точки не удаляются и могут использоваться многократно.
  - Позволяет задать количество врагов для спавна (`enemiesToSpawnCount`).
  - Метод `RestoreEnemy(EnemyData)` восстанавливает врагов из сохранения с учётом оружия/типа атаки.
  - Полная очистка всех активных врагов через `ClearAllEnemies()`.
- **`SpawnerUI`** – отдельный компонент с кнопками «Add Spawn Point» и «Spawn Enemies», связывающий интерфейс с `SpawnManager`.

### 3. Босс – стихии и дальняя атака
- **`BossEnemy`** теперь поддерживает **5 стихий**: Земля, Камень, Лава, Лёд, Снег.
  - Стихия влияет на материал меша голема (`ChangeMeshByElement()`) и на поведение Summon‑способности.
  - Реализована **дальняя атака** (бросок камня), активируемая через выбор типа атаки (`BossAttackType`). Камень летит в игрока, его меш меняется в зависимости от стихии.
  - Два типа атаки переключаются кнопками в UI (`BossUIController`).
  - `IBossProjectileFactory` – абстрактная фабрика для создания снарядов с материалом стихии.
- **Стихийные Summon-способности** полностью инкапсулированы в **`IElementSummonFactory`** и её реализации `DefaultElementSummonFactory`. Больше никакой логики в `BossSummonState` – состояние только запускает корутину из фабрики. Фабрика отвечает за:
  - Земля: `Earth_Fissure` – линии во все стороны через 45°.
  - Камень: колонны, поднимающиеся из земли (управление жизненным циклом внутри фабрики).
  - Лава: `Fire_Meteor` – три метеорита, летящие в ряд к игроку.
  - Лёд: `Ice_PathSpike` – три линии в направлении -30°, 0°, +30° относительно игрока.
  - Снег: `Ice_Shard` – три снежных метеорита, аналогично Fire_Meteor, но с ледяным префабом.
- UI для босса (`BossUIController`) содержит кнопки выбора типа атаки (Melee / Ranged) и кнопки выбора стихии.

### 4. Сохранение и загрузка вариативности
- Класс `GameData` (и `EnemyData`) расширен полями:
  - `meleeRightWeaponIndex`, `meleeLeftWeaponIndex` – индексы выбранного оружия милишника.
  - `evilWatcherAttackType` – тип атаки наблюдателя.
- `GameSaveInteractor` и `GameLoadInteractor` обновлены для сохранения/восстановления этих параметров.
- При загрузке игры старые враги удаляются, и создаются новые в сохранённых позициях с правильным оружием/типом атаки. `SpawnManager` интегрирован в процесс загрузки.

### 5. Архитектурные улучшения
- Активно используются фабрики:
  - `IWeaponFactory` (и `DefaultWeaponFactory`) – создание оружия для `MeleeEnemy`.
  - `IAttackTypeFactory` (и `RandomAttackTypeFactory`) – выбор типа атаки для `EvilWatcher`.
  - `IBossProjectileFactory` – создание метательных камней со стихийным материалом.
  - `IElementSummonFactory` – полный цикл призыва стихийных атак.

## Заключение
После внесения данных изменений враги стали вариативными, босс получил стихийные атаки и выбор типа боя, появилась гибкая система спавна с сохранением состояния. Проект готов к интеграции более сложной логики событий и подсчёта очков.
